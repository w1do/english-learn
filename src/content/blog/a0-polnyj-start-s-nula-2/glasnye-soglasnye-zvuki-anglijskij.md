<h2>Цель урока</h2>

<ul>

	<li>отличать гласные буквы от гласных звуков</li>
	<li>понимать, почему в английском звуков больше, чем букв</li>
	<li>узнать основные короткие и долгие гласные звуки</li>
	<li>познакомиться с важными согласными звуками</li>

</ul>

<p>В слове cat есть три буквы: c-a-t</p>

<p>Но при произношении мы слышим три звука: k-&aelig;-t</p>

<h2>Почему гласные звуки так важны</h2>
</div>

<p>В английском языке гласные звуки часто меняют смысл слова</p>

<p>Иногда два слова отличаются только одним гласным звуком</p>

<h4><strong>Сравните:</strong></h4>

<h4><a href="/uploads/files/ship.mp3">ship [ʃɪp] &mdash; корабль</a></h4>

<p><a href="/uploads/files/sheep.mp3">sheep [ʃiːp] &mdash; овца</a></p>

<p>Разница только в звуках [ɪ] и [iː]</p>

<h4><strong>Ещё пример:</strong></h4>

<p><a href="/uploads/files/full.mp3">full [fʊl] &mdash; полный</a></p>

<p><a href="/uploads/files/fool.mp3">fool [fuːl] &mdash; дурак</a></p>

<p>Разница только в звуках [ʊ] и [uː]</p>

<p>Поэтому важно не просто &ldquo;примерно&rdquo; произносить английские слова, а постепенно учиться слышать и произносить разные гласные звуки</p>

<h2>Почему нельзя заменять английские звуки русскими</h2>
</div>

<p>Когда человек только начинает учить английский, ему хочется заменить непривычные английские звуки русскими</p>

<p><strong>Например:</strong></p>

<ul>
	<li>[&theta;] заменить на с</li>
	<li>[&eth;] заменить на з</li>
	<li>w заменить на в</li>
	<li>[&aelig;] заменить на э</li>
	<li>[ɜː] заменить на ё / э</li>
</ul>

<p>Но это мешает произношению</p>

<p>Иногда вас всё равно поймут</p>

<p>Но речь будет звучать сильно по-русски, а некоторые слова можно перепутать</p>

<h4><strong>Например:</strong></h4>

<p><a href="/uploads/files/think.mp3">think [&theta;ɪŋk] &mdash; думать</a></p>

<p><a href="/uploads/files/sink.mp3">sink [sɪŋk] &mdash; раковина, тонуть</a></p>

<p>Если заменить [&theta;] на s, получится другое слово</p>

<div class="highlight-box" style="margin: 15px 0px; padding: 15px 15px; box-sizing: border-box; background: linear-gradient(135deg, rgb(58, 45, 110), rgb(78, 63, 145)) 0% 0% / auto repeat scroll padding-box border-box rgba(0, 0, 0, 0); color: rgb(255, 255, 255); border-radius: 12px;">
<h2>Как гласные и согласные работают вместе</h2>
</div>

<p>Английские слова строятся из сочетания гласных и согласных звуков</p>

<h3>Например:</h3>

<p><a href="/uploads/files/ttsmaker-file-2026-5-19-16-50-4.mp3">cat [k&aelig;t] &mdash; кот</a></p>

<p>Звуки: k + [&aelig;] + t</p>

<p><a href="/uploads/files/dog.mp3">dog [dɒɡ] &mdash; собака</a></p>

<p>Звуки: d + [ɒ] + ɡ</p>

<p><a href="/uploads/files/ship.mp3">ship [ʃɪp] &mdash; корабль</a></p>

<p>Звуки: ʃ + [ɪ] + p</p>

<p>Гласные дают слову &ldquo;сердце&rdquo; звучания</p>

<p>Согласные создают форму слова</p>

<p>Если неправильно произнести гласный или согласный звук, слово может стать непонятным или превратиться в другое слово</p>

<div class="highlight-box" style="margin: 15px 0px; padding: 15px 15px; box-sizing: border-box; background: linear-gradient(135deg, rgb(58, 45, 110), rgb(78, 63, 145)) 0% 0% / auto repeat scroll padding-box border-box rgba(0, 0, 0, 0); color: rgb(255, 255, 255); border-radius: 12px;">

	<h4>Гласные звуки произносятся свободно</h4>
