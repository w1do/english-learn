<h3><strong>Краткий итог</strong></h3>

<p>Простые команды и инструкции помогают понимать задания на английском языке</p>

<p><strong>Главные команды урока:</strong></p>

<ul>
	<li>listen &mdash; слушай / слушайте</li>
	<li>repeat &mdash; повтори / повторите</li>
	<li>write &mdash; напиши / напишите</li>
	<li>choose &mdash; выбери / выберите</li>
	<li>read &mdash; прочитай / прочитайте</li>
	<li>say &mdash; скажи / скажите</li>
	<li>look at &mdash; посмотри на</li>
	<li>open &mdash; открой / откройте</li>
	<li>close &mdash; закрой / закройте</li>
	<li>answer &mdash; ответь / ответьте</li>
</ul>

<p><strong>Главные правила:</strong></p>

<ul>
	<li>простая команда часто начинается с глагола</li>
	<li>в команде обычно не нужно слово you</li>
	<li>please делает команду вежливее</li>
	<li>don&rsquo;t используется для отрицательной команды</li>
	<li>после listen часто нужен to</li>
	<li>после look часто нужен at</li>
