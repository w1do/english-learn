<div class="highlight-box" style="margin: 10px 0px; padding: 10px 10px; box-sizing: border-box; background: linear-gradient(135deg, rgb(58, 45, 110), rgb(78, 63, 145)) 0% 0% / auto repeat scroll padding-box border-box rgba(0, 0, 0, 0); color: rgb(255, 255, 255); border-radius: 12px;">
<h2><strong>Что такое транскрипция</strong></h2>
</div>

<p><strong>Транскрипция</strong> &mdash; это запись слова с помощью специальных звуковых символов</p>

<p>Она показывает не то, как слово пишется, а то, как слово произносится</p>

<p><strong>Например:</strong></p>

<p><a href="/uploads/files/ttsmaker-file-2026-5-19-16-50-4.mp3">cat [k&aelig;t] &mdash; кот</a></p>

<p>Слово пишется так: cat</p>

<p>А произносится по звукам так: k&aelig;t</p>

<p>То есть транскрипция помогает увидеть настоящие звуки слова</p>

<div class="highlight-box" style="margin: 10px 0px; padding: 10px 10px; box-sizing: border-box; background: linear-gradient(135deg, rgb(58, 45, 110), rgb(78, 63, 145)) 0% 0% / auto repeat scroll padding-box border-box rgba(0, 0, 0, 0); color: rgb(255, 255, 255); border-radius: 12px;">
<h2>Зачем нужна транскрипция</h2>
</div>

<p><img alt="" src="/uploads/files/%D0%97%D0%B0%D1%87%D0%B5%D0%BC%20%D0%BD%D1%83%D0%B6%D0%BD%D0%B0%20%D1%82%D1%80%D0%B0%D0%BD%D1%81%D0%BA%D1%80%D0%B8%D0%BF%D1%86%D0%B8%D1%8F.png" style="width:800px"></p>

<p><strong>Ещё примеры:</strong></p>

<p><a href="/uploads/files/two.mp3">two [tuː] &mdash; два</a></p>

<p><a href="/uploads/files/eight.mp3">eight [eɪt] &mdash; восемь</a></p>

<p><a href="/uploads/files/daughter.mp3">daughter [dɔːtə] &mdash; дочь</a></p>

<p><a href="/uploads/files/knife.mp3">knife [naɪfv] &mdash; нож</a></p>

<p>Если смотреть только на буквы, произношение может быть непонятным</p>

<p>Транскрипция помогает читать слово правильно</p>

<p>Написание и произношение &mdash; разные вещи</p>

<h3><strong>В английском важно разделять две вещи:</strong></h3>

<p><strong>Spelling</strong> &mdash; как слово пишется</p>

<p><strong>Pronunciation</strong> &mdash; как слово произносится</p>

<p><strong>Например:</strong></p>

<p><a href="/uploads/files/phone.mp3">phone [fəʊn] &mdash; телефон</a></p>

<p>Слово пишется так: phone</p>

<p>Но произносится так: fəʊn</p>

<p>Буквы ph дают звук f</p>

<p>Буква e в конце слова не произносится</p>

<p>Ещё пример:</p>

<p><a href="/uploads/files/school.mp3">school [skuːl] &mdash; школа</a></p>

<p>В слове school есть буквы s-c-h-o-o-l, но произношение не совпадает с каждой буквой отдельно</p>

<h2>Почему нельзя писать английские звуки русскими буквами</h2>

<p><img alt="" src="/uploads/files/%D0%9F%D0%BE%D1%87%D0%B5%D0%BC%D1%83%20%D0%BD%D0%B5%D0%BB%D1%8C%D0%B7%D1%8F%20%D0%BF%D0%B8%D1%81%D0%B0%D1%82%D1%8C%20%D0%B0%D0%BD%D0%B3%D0%BB%D0%B8%D0%B9%D1%81%D0%BA%D0%B8%D0%B5%20%D0%B7%D0%B2%D1%83%D0%BA%D0%B8%20%D1%80%D1%83%D1%81%D1%81%D0%BA%D0%B8%D0%BC%D0%B8%20%D0%B1%D1%83%D0%BA%D0%B2%D0%B0%D0%BC%D0%B8.png" style="width:800px"></p>

<p><strong>Например:</strong></p>

<p><a href="/uploads/files/think.mp3">think [&theta;ɪŋk] &mdash; думать</a></p>

<p>Звук &theta; нельзя точно передать русской буквой с или ф</p>

<p><a href="/uploads/files/this.mp3">this [&eth;ɪs] &mdash; этот</a></p>

<p>Звук &eth; тоже нельзя нормально передать русскими буквами</p>

<p>Поэтому лучше постепенно привыкать к настоящей английской транскрипции</p>

<div class="highlight-box" style="margin: 10px 0px; padding: 10px 10px; box-sizing: border-box; background: linear-gradient(135deg, rgb(58, 45, 110), rgb(78, 63, 145)) 0% 0% / auto repeat scroll padding-box border-box rgba(0, 0, 0, 0); color: rgb(255, 255, 255); border-radius: 12px;">
<h2>Что показывает транскрипция</h2>
</div>

<p><strong>Транскрипция показывает:</strong></p>

<ul>
	<li>
	<p>какие звуки есть в слове</p>
	</li>
	<li>
	<p>какие буквы не произносятся</p>
	</li>
	<li>
	<p>где звук короткий</p>
	</li>
	<li>
	<p>где звук долгий</p>
	</li>
	<li>
	<p>как звучат сложные английские звуки</p>
	</li>
	<li>
	<p>как слово реально произносится</p>
	</li>
</ul>

<p><strong>Например:</strong></p>

<p><a href="/uploads/files/2026-05-19-214730_131405.mp3">name [neɪm] &mdash; имя</a></p>

<p>В слове name буква e в конце не произносится</p>

<p>Но она влияет на чтение буквы a</p>

<p><a href="/uploads/files/knife.mp3">knife [naɪf] &mdash; нож</a></p>

<p>В слове knife буква k не произносится</p>

<p><a href="/uploads/files/teacher.mp3">teacher [tiːtʃə]&nbsp;&mdash; учитель</a></p>

<p>В конце слова слышится слабый звук ə</p>

<div class="highlight-box" style="margin: 10px 0px; padding: 10px 10px; box-sizing: border-box; background: linear-gradient(135deg, rgb(58, 45, 110), rgb(78, 63, 145)) 0% 0% / auto repeat scroll padding-box border-box rgba(0, 0, 0, 0); color: rgb(255, 255, 255); border-radius: 12px;">
