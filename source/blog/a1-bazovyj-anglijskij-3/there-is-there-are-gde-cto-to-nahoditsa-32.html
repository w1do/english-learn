There is / there are

Цель урока

В этом уроке вы изучите конструкцию there is / there are и поймёте, как говорить, что где-то что-то есть или находится

После урока вы сможете:

  • понимать значение there is и there are
  • говорить, что предмет находится в комнате, доме, городе или другом месте
  • выбирать there is для одного предмета и there are для нескольких предметов
  • строить утверждения, отрицания и вопросы
  • использовать there is / there are с предлогами места: in, on, under, near, next to
  • отличать there is / there are от have / has
  • не переводить there буквально как “там” в каждом предложении

Что это за тема простыми словами

Главная идея темы

Главная идея простая: сначала говорим there is или there are, потом называем предмет, потом место

There is / there are + object + place

There is — когда предмет один

There is используется, когда мы говорим об одном предмете, одном человеке или одном явлении

Когда использовать

Самая важная схема:

Краткий итог

There is / there are — это базовая конструкция для описания того, что где-то что-то есть или находится

Главные правила урока:

  • there is используется с одним предметом или неисчисляемым существительным
  • there are используется с несколькими предметами
  • после there is с одним исчисляемым предметом часто используется a или an
  • в отрицаниях not ставится после is или are
  • в вопросах is или are ставится перед there
  • there is / there are не равны have / has
  • в английском часто начинаем с there is / there are, а место ставим в конце

Если хотите сказать “где-то есть что-то”, чаще всего начинайте с there is или there are
